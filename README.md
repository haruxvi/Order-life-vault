## Español

Vault de Obsidian para ordenar la vida personal, académica y de entrenamiento, con **IA 100 % local** (sin API keys ni servicios en la nube).

### Qué incluye
- **Notas periódicas**: día, semana, mes, trimestre y año, con resúmenes, valoraciones y una Rueda de la Vida.
- **Académico**: horario, promedios, la nota que te falta para aprobar y próximas evaluaciones (escala 1–7).
- **Entrenamiento**: registro interactivo de series, descanso con aviso, marcas personales y progresión.
- **Biblioteca**: juegos, libros, anime, manga, películas y series, con portadas.
- **Conocimiento**: mapas de contenido, notas conectadas, panel de conexiones, preguntas a todo el vault y repaso espaciado.
- **Bandeja de entrada**, agenda, hábitos y etiquetas organizadas.

Todo lo hace el plugin propio **Raíz** (`.obsidian/plugins/raiz`).

### Requisitos
1. [Obsidian](https://obsidian.md) 1.4 o superior. Activa los plugins de la comunidad al abrir el vault.
2. Para la IA, elige en **Ajustes → Raíz → Inteligencia artificial**:
   - **Local**: [Ollama](https://ollama.com) (luego `Ctrl+P` → **Raíz: Descargar modelos de IA recomendados**), LM Studio u OpenClaw.
   - **En la nube, con tu API key**: OpenAI (GPT), Anthropic (Claude), xAI (Grok), DeepSeek, Kimi, Qwen, Gemini, OpenRouter, Groq u OpenCode Zen.
   - **Cualquier otra API compatible con OpenAI.**

   Las keys se guardan en el Llavero de Obsidian, nunca en el vault.
3. Instala desde la tienda de Obsidian los plugins no incluidos (ver [TERCEROS.md](TERCEROS.md)).

La guía completa está en [00 Dashboard/Guía Raíz.md](00%20Dashboard/Guía%20Raíz.md).

### Aviso sobre software de terceros
Los plugins de la comunidad que vienen en `.obsidian/plugins` **no son de mi autoría**. Pertenecen a sus autores y se incluyen sin modificaciones, cada uno con su licencia original. El detalle de autores, licencias y repositorios está en **[TERCEROS.md](TERCEROS.md)**.

## English

An Obsidian vault for organizing personal, academic and training life, with **100% local AI** (no API keys, no cloud services). The vault's content and interface are in Spanish.

### What's inside
- **Periodic notes**: day, week, month, quarter and year, with summaries, ratings and a Wheel of Life.
- **Academics**: class schedule, grade averages, the grade you need to pass, and upcoming exams (Chilean 1–7 scale).
- **Training**: interactive set logging, rest timer with alerts, personal records and progression charts.
- **Library**: games, books, anime, manga, movies and TV shows, with cover art.
- **Knowledge**: maps of content, linked notes, a connections panel, questions over the whole vault, and spaced repetition.
- **Inbox**, agenda, habits and tag organization.

All of it is handled by my own plugin, **Raíz** (`.obsidian/plugins/raiz`).

### Requirements
1. [Obsidian](https://obsidian.md) 1.4 or later. Enable community plugins when you open the vault.
2. For the AI, pick a provider in **Settings → Raíz → Inteligencia artificial**:
   - **Local**: [Ollama](https://ollama.com) (then `Ctrl+P` → **Raíz: Descargar modelos de IA recomendados**), LM Studio or OpenClaw.
   - **Cloud, with your own API key**: OpenAI (GPT), Anthropic (Claude), xAI (Grok), DeepSeek, Kimi, Qwen, Gemini, OpenRouter, Groq or OpenCode Zen.
   - **Any other OpenAI-compatible API.**

   Keys are stored in Obsidian's keychain, never inside the vault.
3. Install the plugins that are not bundled from the Obsidian community store (see [THIRD_PARTY.md](THIRD_PARTY.md)).
